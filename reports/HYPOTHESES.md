# Конкурирующие архитектурные гипотезы и выбор

Дата: 2026-09-09. Пререгистрация ДО запуска экспериментов.

## Кандидаты

### H-A: «Эпизодический причинный агент» (EMCA — Episodic Model-based Causal Agent)
Ядро: append-only эпизодическая память (никогда не перезаписывается) + байесовско-частотный причинный граф, обновляемый отдельно из observational и interventional переходов (do-флаг на каждом действии агента) + планирование поиском по графу + цели из внутренних генераторов (homeostasis, learning progress, empowerment) + самомодель (оценка своих навыков, обновляемая из исходов).
Субъектность = наблюдаемая персистентность: память и цели переживают сброс рабочего контекста.

### H-B: «Активный вывод с эпизодическим генеративным модулем»
Ядро: expected free energy как единая валюта; генеративная модель — kNN по эпизодам (не нейросеть).
Плюс: теоретическая целостность. Минус: по литературе плохо масштабируется (src_973284d453d0); EFE-планирование на kNN-модели вырождается в тот же поиск, что у H-A, но с более дорогой оценкой; риск неинтерпретируемых срывов.

### H-C: «Нейроморфный ансамбль» (spiking + STDP)
Плюс: онтогенетическая правдоподобность. Минус: для минимального прототипа нужны симуляторы (brian2/nest) и недели тюнинга; причинность и целеполагание не возникают сами — их всё равно надстраивать символически. Не реализуемо в срок с измеримой фальсификацией.

### H-D: «Гибрид LLM-ядро + внешняя причинная память»
Плюс: быстрый старт. Минус: не «принципиально отличная от Transformer/LLM» архитектура — прямо исключена условием задачи.

## Критерии выбора (проверяемые, назначены ДО экспериментов)

| Критерий | H-A | H-B | H-C | H-D |
|---|---|---|---|---|
| Реализуемость прототипа за один ход | ✓ | ✓ | ✗ | ✓ |
| Все 6 свойств в одном ядре | ✓ | частично | ? | ✗ (LLM-ядро) |
| Фальсифицируемость на маленькой среде | ✓ (граф читаем) | слабее | ✗ | слабее |
| Не зависит от Transformer/LLM | ✓ | ✓ | ✓ | ✗ |
| Не требует GPU/обучения корпусом | ✓ | ✓ | ✓ | ✗ |

**Выбор: H-A (EMCA).** Единственный кандидат, где все шесть свойств — части одного механизма, а не надстройки, и где каждый механизм независимо отключаем (абляции) — значит, неудачу можно атрибутировать конкретному модулю, а не «архитектуре вообще».

## Пререгистрация фальсификации (пороги назначены ДО прогона)

Среда: Terrarium (см. env_terrarium.py) — сетка, ресурсы, скрытый конфаундер (сезон), смена режима в середине жизни, цепочка «рычаг→дверь→сокровище», требующая планирования.

- **E1 (причинность):** после фазы A агент должен использовать рычаг, а не коррелирующий с ним бесполезный объект; метрика — доля do-подтверждённых рёбер в истинном графе ≥ 0.5 и доля ложных рёбер ≤ 0.2. FAIL → причинный модуль не работает.
- **E2 (память/персистентность):** после сброса рабочего контекста (эпизодический буфер очищен, долговременная память и цели сохранены) агент восстанавливает компетентность (выживание/сбор) быстрее, чем с нуля, в ≥ 2 раза по шагам. FAIL → «память» — не память.
- **E3 (планирование):** агент доводит цепочку рычаг→дверь→сокровище до конца ≥ 1 раза за жизнь без подсказок; baseline-ы (random, Q-learning, n-gram) — 0. FAIL → планирование отсутствует.
- **E4 (самообучение/адаптация):** после смены режима в середине жизни агент возвращается к компетентности ≤ 1500 шагов (Q-learning в тех же условиях — деградирует или восстанавливается дольше). FAIL → нет runtime-обучения.
- **E5 (цели):** за жизнь агент порождает ≥ 2 внутренних цели, которые не сводятся к немедленному выживанию, и преследует их ≥ 100 шагов суммарно. FAIL → целеполагание — артефакт.
- **E6 (субъектность как персистентность):** после сброса контекста ≥ 1 цель из «до» остаётся активной «после» и достигается. FAIL → субъектность не наблюдаема.

Абляции (те же пороги): EMCA без причинного графа (планирование по частотам), без эпизодов (только граф), без генераторов целей (только homeostasis), без самомодели.
Baseline: random, tabular Q-learning (ε-greedy), n-gram (контекстно-ограниченный предсказатель действий).

Отрицательные результаты сохраняются в results/ независимо от исхода.
