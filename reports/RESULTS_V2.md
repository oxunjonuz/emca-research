# RESULTS v2 — TerrariumV2 + EMCA v2.2 (специфичность-гейтированный идентификатор)

**Ход 96.** Полный цикл: среда v2 → независимая верификация механики → toy-проверка
разводящей способности среды до матрицы (директива TZ.md) → два дефекта среды,
пойманные toy-проверкой и починенные до матрицы → матрица 10×3×6000 → анализ
независимым скриптом → детерминизм проверен повторным прогоном.

## Что построено

- `env_terrarium_v2.py` — TerrariumV2: активный конфаундер-приманка (фаза
  warm/cold; в warm колокол светится, ягоды цветут у колокола, колокол звонит
  сам; `grasp` никогда не имеет эффекта), редкое событие (блуждающее фруктовое
  дерево, +25 энергии/reward 8, ~раз в 300 шагов), брутфорс-гейт (сокровище
  требует рычаг И ключ; ключ материализуется только в cold, живёт 80 шагов),
  scent-градиент (единственный канал навигации к объектам вне 3×3 вида),
  холодные ягоды выживания в дальней зоне.
- `agent_emca_v2.py` — EMCA v2.2: S7 specificity-gate в идентификаторе
  (pooled_others ≤ 0.10), ctx-ключ дополнен видимым следом фазы (светимость
  колокола) и признаками key/tree; scent-навигация; цели key/tree/treasure;
  арбитраж целей v2.2 (демоция после 3 экспираций); always-on фуражинг.
  Версия идентификатора пишется в каждый лог (правило TZ.md: не смешивать
  v2.2-spec и v2.1-pooled молча).
- `verify_env_v2.py` — 19/19 PASS независимой проверки механики (оракул:
  P(ring|do(grasp))=P(ring|do(wait))=0.511; random: 0 сокровищ в 5×6000).
- `sanity_env_v2.py` — toy-проверка среды ДО матрицы (пререгистрирована).
- `run_life_v2.py` / `driver_v2.py` — матрица 10 условий × 3 сида × 6000 шагов.
- `analyze_v2.py` — независимый анализ сырых JSON (пересчитывает все агрегаты).

## Toy-проверка до матрицы (директива TZ.md — «сначала маленькой проверкой»)

Пререгистрированные критерии V1–V5, прогон 8000 шагов × 3 сида, реальный агент:

- **V1 PASS (3/3)** — корреляция обманута: assoc содержит (grasp, bell_rang).
- **V2 FAIL (0/3) — находка:** pooled-контраст v2.1 САМ отвергает приманку у
  реального агента (rate_a 0.44–0.51 < pooled 0.53–0.60). Причина: eps-шум
  (15%) делает все действия фазово-сбалансированными — агент сам
  декоррелирует свои действия от фазы. Приманка ловит только наблюдательные
  политики без собственного шума (toy-харнесс хода 95) или чистую корреляцию.
  Вывод: в матрице v2 идентификаторы v2.1/v2.2 НЕ обязаны различаться на
  поведении — и действительно не различаются (см. ниже). Это не провал
  среды: среда разводит causal/correlational (E1), но не v2.1/v2.2, потому
  что рандомизированная политика агента — сам по себе конфаундер-контроль.
- **V3 PASS (3/3)** — v2.2 чист от приманки.
- **V4 PASS (2/3)** — истинные рёбра выживают.
- **V5 FAIL (0/3) — дизайн-дефект, пойман ДО матрицы:** дерево/ключ
  недостижимы (tree в поле зрения 38 раз за 8000 шагов, 0 поеданий; агент с
  3×3 видом не может найти объект, который видит только с расстояния 1).
  Починено до матрицы: scent-градиент (одинаковый для всех рук) + холодные
  ягоды (без них агент умирал в каждой cold-фазе: 35 смертей/8000 → 12/6000).

## Вердикты E1–E6 (пороги пререгистрированы до матрицы)

- **E1 причинность PASS.** emca: (press,lever) и (eat,ate) в 3/3; приманка в
  causal 0/3; приманка в assoc (emca_nocausal) 2/3. Среда v2 действительно
  разводит causal/correlational — то, чего v1 не могла в принципе.
- **E3 планирование PASS.** emca сокровища [1,2,1] по сидам; random 0/3 —
  брутфорс-гейт держит. Разница с v1: теперь сокровище требует цепочки
  рычаг→ключ→дверь, а не одной удачи.
- **E5 редкие события PASS.** emca 48.7 плодов против qlearn/ngram 0.0.
  Любопытство (цель tree + scent-навигация) находит редкое событие, которого
  реактивные baseline-ы не видят вовсе.
- **E2 память — измерено, вердикт не заявляется** (урок v1: порог без
  калибровки). post_reset/pre_life: 1.42/0.80/0.70 (emca) против
  1.33/0.80/0.70 (amnesia) — различий между нормой и амнезией нет: в этой
  среде выживание не зависит от долгосрочной памяти (ягоды видны локально).
- **E4 адаптация — не подтверждена.** Смерти до/после flip: emca 6→8, 5→8,
  6→5. Деградация после flip есть (2/3), но амплитуда мала; qlearn/ngram
  стабильны в ~13. Различие слабое, честно фиксируем: не подтверждено.
- **E6 субъектность — по букве FAIL (0/3), по ledger'у PASS (3/3).**
  Критерий «тот же kind перевыпущен после reset» мерил перевыпуск, а не
  персистентность. Полный per-goal ledger (независимый прогон): цель,
  активная на момент reset, переживает его и достигается после — seed1:
  tree born 3762, achieved 4507 (reset 4500); seed2: treasure born 4481,
  active после reset; seed3: treasure born 4085, achieved 4998. Цель как
  намерение переживает сброс контекста во всех 3 сидах. Критерий был
  ошибочен, результат — нет; оба факта зафиксированы.

## Отрицательные и трудные результаты (не смягчены)

1. **emca == emca_nocausal == emca_v21 — все три идентичны до третьего знака.**
   В v2-среде контрастный идентификатор (с гейтом и без) и ассоциативный
   дают одинаковые рёбра и одинаковое поведение. Причина найдена измерением:
   eps-шум агента балансирует действия по фазам, приманка не проходит ни в
   один идентификатор, и различия между ними не в чём проявиться. S7-гейт
  кусает только наблюдательные политики (toy-харнесс хода 95). Гипотеза
  «специфичность необходима агенту» НЕ подтверждена — она подтверждена
  только для наблюдателя без собственного шума.
2. **Полный агент хуже своих абляций — снова, и сильнее.** emca 578 против
   noepis 3471 / nogoals 2988 / noself 4169. Механизм найден и в v2: цель
   «key» монополизировала жизнь (5178/6000 шагов в первом прогоне),
   экспирая 4 раза по 1200 шагов, пока цепочка рычаг+ключ была собрана 147
   шагов. Починено арбитражем v2.2 (демоция после 3 экспираций) и always-on
   фуражингом — это подняло emca с −54 до 578, но разрыв с абляциями
   остался: генераторы целей по-прежнему налог, теперь меньший.
3. **emca_noself генерирует 306 целей и достигает 305** — без self-model
   цели не помечаются достигнутыми и перевыпускаются бесконечно; это
   артефакт учёта (цель «empowerment» выполняется почти сразу), не свойство
   субъектности. Зафиксировано как дефект метрики, не как результат.
4. **E6-критерий был ошибочен** (см. выше) — правка критерия после прогона
   зафиксирована здесь явно, история не переписана.

## Вердикт по архитектуре (скромная рамка хода 94 сохранена)

Подтверждено измерением в v2: эпизодически-причинный планировщик с
целеобразованием берёт сокровище, требующее трёхшаговой цепочки, и находит
редкое событие, недостижимое для tabular RL/n-gram (E3, E5); среда v2
действительно разводит причинность и корреляцию (E1) — впервые в этой
кампании. Не подтверждено: необходимость S7-гейта для агента (подтверждена
только для наблюдателя), окупаемость генераторов целей (налог остался),
адаптация к смене режима (E4), память как выживание (E2 — среда не
требует). Идентичность emca/emca_nocausal в v2 — не повтор ошибки v1:
в v1 среда не содержала различающей структуры, в v2 структура есть, но
агентова собственная рандомизация её нейтрализует для идентификатора,
оставляя её видимой только для корреляции (assoc ловит приманку 2/3).
