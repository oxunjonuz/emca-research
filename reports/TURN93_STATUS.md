## Честные дефекты, найденные в собственном коде в ходе работы (все исправлены, все зафиксированы)

- v1 «причинность» считала рёбра по co-occurrence в «разнообразном» контексте → ложные
  рёбра (left→died, right→treasure при p=1.0). Переписано на контрастный метод.
- Компрехеншн итерировался по ключам dict вместо значений → effects = {'s','p','r','e'}
  (буквы слова 'press'). Классический silent bug.
- Знаменатель рёбер не учитывал пробы без эффекта → press→lever был «100%» при 2 пробах.
  Введены явные trial-счётчики.
- Планировщик v1 содержал захардкоженную цепочку рычаг→дверь (утечка знания задачи в
  агент) — удалена, планирование стало generic (causal edge → episodic context →
  interventional exploration).
- Смертельная спираль: цель с длинным дедлайном блокировала гомеостаз (44 смерти,
  seed 3). Фикс: приоритет выживания в арбитре.
